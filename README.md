# SHENZICHEN Website

Personal portfolio for **shenzichen.website**.

## Stack

- Next.js
- React
- TypeScript
- Tailwind CSS
- Custom CSS for the visual system

## Local development

```bash
npm install
npm run dev
```

Open http://localhost:3000.

## Direction

Programmer · AI · Games · Eastern Culture

The site is intentionally frontend-first. Backend services can be added later without replacing the current portfolio structure.
